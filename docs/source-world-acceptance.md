# 源码世界第一功能目标

四项都须有当前版本的验收证据。上游 GraphFlow 的说明、以前的测试结果和当前源码中的功能入口都不代替本产品实跑。

| 标准 | 通过条件 | 当前缺口 |
| --- | --- | --- |
| 一条 MCP 接入，跨会话记忆与技能学习 | 同一客户端接入一次，授权夹具工作区；关闭旧会话并在新会话召回有据的项目结果及适用技能。另验撤销、项目隔离、索引→摘要→详情，并区分星愿记忆和项目台账。 | 工作区授权和跨会话路径待联合实测；项目结果不会自动改成技能。 |
| 离线 AST 图谱和预算内上下文，测量节省效果 | 同一组有正确答案的代码任务，对照直接读文件，固定检索范围和测量方式；统计真实工具回包、Agent 额外调用和任务正确率，按项目/语言报告中位数及范围。相似历史和匹配技能须另外验证相关性和预算。 | 有静态图谱和预算；现有基准仅能报告合成检索的估算量，不能支持「实测约 98%」。 |
| Hook 自动结果捕获与可信学习 | 在可信宿主上自动接收最小结果字段；重复事件不重记、错误工作区不串数据。伪造报告、无证据回填、失效证据、外部指令和未信任 Hook 不得自动晋升成经验。用户能追溯来源或撤销。 | Codex SessionStart 只提示如何查询，不捕获任务结果。第一步已让自动上下文只返回结构化证据，不带自由文本；未做完整防投毒对抗验收。 |
| 断网、无模型 API 密钥、至少 15 个代理 | 运行依赖齐备后，在隔离且断网的环境验冷启动、索引、切片、历史与技能本地召回。按独立客户端记录首次接入、工具调用、工作区解析及 Hook 支持层级，至少 15 个客户端有实机证据。 | 不把本地引擎离线和云端 Agent 离线混在一起；未继承上游安装器覆盖。 |

先用 Codex 和夹具贯通前三项主路径，再扩展多宿主矩阵。Hook 不采集聊天正文，不执行编辑或测试。未经操作者关联的测试引用只算报告线索；关联测试即使通过也只是历史证据，不能代替当前验证。

基准输出中 `token_comparison` 只比较合成夹具的一次符号读取。不把项目全部内容作为人为放大的基线，小文件可能出现负节省。正式测量应保留各样本的基线、工具输出、是否成功、测量器和版本。
